# 1. What is Data?

Data can be anything that needs to be stored in memory.

Examples:
- Numbers
- Images
- Videos
- Text
- Audio

Computers store all data in binary format (0s and 1s).

---

# 2. Binary Number System

Computers understand only two states:

- 0 (Low Voltage)
- 1 (High Voltage)

Example:

Decimal:
15

Binary:
1111

---

# 3. Micro Transistors

Computers contain millions of tiny transistors on the motherboard.

A transistor understands only two electrical states:

- High Voltage → 1
- Low Voltage → 0

This is why computers work using binary numbers.

---

# 4. Memory Units

Smallest unit of memory:

**Bit**

Conversions:

- 4 Bits = 1 Nibble
- 8 Bits = 1 Byte
- 4 Bytes = 1 Integer (int)

Example:

1 Byte = 8 Bits

Maximum value stored in 1 Byte:

11111111 = 255

---

# 5. Why Data Types were Introduced?

During Java 1.0 (1995):

- RAM was very limited (around 4 MB)
- Memory was expensive

To use memory efficiently, Java introduced Data Types.

Data Types tell Java:

- How much memory should be allocated
- What type of value can be stored

---

# 6. Primitive Data Types

Java provides 8 primitive data types.

## Numeric

### Whole Numbers

- byte
- short
- int
- long

### Decimal Numbers

- float
- double

### Character

- char

## Boolean

- boolean

Stores only:

- true
- false

---

# 7. Reference Data Types

Reference variables store the memory address of objects.

Examples:

- String
- Arrays
- Classes
- Interfaces
- Enums

---

# 8. ASCII Representation

Every character has a numeric value.

Examples:

'A' = 65

'a' = 97

ASCII helps computers represent characters using numbers.

---

# Key Takeaways

- Computers understand only binary (0 and 1).
- Bit is the smallest memory unit.
- Data Types improve memory efficiency.
- Java has 8 primitive data types.
- Reference variables store object addresses.
- Characters are represented using ASCII values.
